# Building-with-Claude
Using Claude to build a website using HTML, CSS and JavaScript.
I always wanted to learn how to build a website, using tools like HTML. Thanks to the help of AI I am making progress on that path!! I realized that this is NOT easy! but it's also very intriguing and a fun way to get creative and build something from scratch. 
In this project, I worked along Claude to build a webpage called "Sensible Sage" which has a health/wellness focus. Claude taught me the various tools used to make webpages like. I learned about HTML, a tool that can be compared to the skeleton this is where all important objects or bones that make up a website, it then divided into CSS and Javascript. CSS is responsbile for the over look and feel of a website; things such as color, font. spacing. etc can be customized using this tool. Javascript is the nervous system of the webpage; this tool has two core concepts: getElementId & addEventListener. getElementID is used for identifying a unique name tag and addEventListener gives that id or button an action, so every-time that button id is interacted with it will produce that specific action every-time.
