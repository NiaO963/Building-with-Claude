# Building-with-Claude
Using Claude to build a website using HTML, CSS and JavaScript.
I have always wanted to learn how to build a website using tools like HTML. Thanks to the help of AI, I am making great progress on that path! I realized that this is not easy, but it is also very intriguing and a fun way to get creative and build something from scratch.

In this project, I worked alongside Claude to build a webpage called "Sensible Sage," which has a health and wellness focus. Claude taught me about the various tools used to make webpages. I learned about HTML, a tool that can be compared to a skeleton—this is where all the important objects or bones that make up a website are located. The website elements are then styled and animated using CSS and JavaScript.

CSS is responsible for the overall look and feel of a website; things such as color, font, and spacing can be customized using this tool. JavaScript acts as the nervous system of the webpage. This tool has two core concepts: getElementById and addEventListener. getElementById is used for identifying a unique element, and addEventListener gives that element or button an action, so every time that button is interacted with, it performs that specific action.

With that, Day 1 is complete! I am posting the link to my HTML website, and it will be updated as I continue to learn and build with Claude.
